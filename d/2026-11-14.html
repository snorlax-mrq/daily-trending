怎麼讀

名次為各榜單原始排序。漲跌比較前一個有紀錄的日期；走勢為近九日名次，線在上方代表名次較好。「新」表示本站紀錄中首次出現，不代表該項目當天才發布。

增速榜比較不一樣：那是本站每天自己抓 GitHub 總星數算出來的增量，不用 GitHub Trending 顯示的「stars today」（那是滾動窗估計值，同一天抓兩次會不一樣，也和榜單排序無關）。
